# Control Systems - MATLAB Labs

A collection of MATLAB solutions developed throughout my Control Systems class.
## 🧰 Main Methods Used
*   **Vector Method:** Using simple row arrays of numbers (`poly`, `conv`, `roots`) to store and multiply polynomials.
*   **Symbolic Math:** Using text symbols instead of raw numbers (`syms`, `laplace`, `ilaplace`) to solve algebra equations and circuit loops.
*   **System Models:** Turning equations into actual control system blocks like transfer functions (`tf`) and factored forms (`zpk`).

### Lab 2: Polynomials, Laplace Transforms, and Circuit Modeling
This lab uses MATLAB shortcuts to bypass doing pages of algebra arithmetic by hand.
*   **Polynomials & Fractions:** Multiplying out large brackets, finding roots, and expanding partial fractions with `residue`.
*   **Laplace Transforms:** Switching equations between the time domain and frequency domain using symbolic variables.
*   **Circuit Solver:** Setting up a 3x3 matrix to quickly solve for three unknown loop currents in a circuit diagram.
